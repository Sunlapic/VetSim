# Пакет №335 — убран draw_arc (падение в твоей версии GameMaker)

Твоя ошибка из консоли:

```
Variable obj_staff_assistant.draw_arc(...) not set before reading it.
at gml_Script_wait_bar_capsule_outline (line 393)
```

Это моя ошибка в №334: я нарисовал торцы капсулы функцией
`draw_arc`, а её **нет в твоей версии GameMaker** — игра восприняла
вызов как чтение необъявленной переменной и уронила отрисовку
персонала.

## Исправление

Полуокружности теперь собираются из 12 коротких отрезков
`draw_line` (`wait_bar_arc`): `draw_line`, `lengthdir_x`,
`lengthdir_y` существуют во всех версиях GameMaker. На радиусе
4 пикселя отрезки сливаются в гладкую дугу — визуально та же
капсула, что на превью №334.

Всё остальное без изменений: стиль №2 «СТЕКЛО», постоянная капсула,
цвет пустеет внутри, торцы круглые, позиция над головой.

## Проверено

- в скрипте не осталось ни одного `draw_arc(` (поиск по файлу);
- статический линтер: одно прежнее замечание, не относится к пакету;
- используются только древние функции: draw_line, draw_circle,
  draw_rectangle, draw_ellipse, lengthdir_*, draw_set_*;
- копия в пакете совпадает с исходником по md5.
