# Пакет №344 — места работы по покупке, а не по объектам в комнате

Твоя находка: купил вторую клинику, стационар ещё не открыт, а врача
уже можно послать в стационар. Причина: №343 смотрел на объекты в
комнате (`obj_inpatient_controller`), а они стоят в комнате всегда —
решают не они, а **покупка** помещения.

## Исправление

В списке «МЕСТО» карточки сотрудника теперь:

- **СТАЦИОНАР** — только если палата куплена (`clinic_ward_is_open()`);
- **ХИРУРГ / АНЕСТЕЗИОЛОГ / ОПЕРАЦИОННАЯ** — только если
  операционная предусмотрена клиникой и куплена
  (`clinic_operating_is_open()`);
- иначе только «НА ПРИЁМЕ».

Пакет включает правки №343 — если 343 не ставил, просто ставь 344.

## Проверено

- статический линтер: одно прежнее замечание (par_staff, не относится);
- функции-источники (`clinic_ward_is_open`, `clinic_operating_is_open`)
  читают данные покупок клиники (`global.clinic_rooms_open`);
- копия в пакете совпадает с исходником по md5.

## Не проверялось

Запуск в GameMaker (нет `.yyp`). Во второй клинике без купленной
палаты в «МЕСТО» не должно быть «СТАЦИОНАР».
