# Пакет №343 — в выборе места работы только то, что есть в клинике

Твоя просьба: если операционной нет или она ещё не открыта — нельзя
отправить сотрудника в операционную, такой кнопки вообще не должно
быть. «Если в клинике только приём — нажимаешь на место, и там
ничего нет, только приём».

## Что меняется

Список «МЕСТО» в карточке сотрудника теперь собирается по наличию
комнат в клинике:

- **НА ПРИЁМЕ** — всегда;
- **СТАЦИОНАР** — только если в комнате есть стационар
  (`obj_inpatient_controller`);
- **ХИРУРГ / АНЕСТЕЗИОЛОГ** (врачу) и **ОПЕРАЦИОННАЯ** (ассистенту) —
  только если в комнате есть операционная (`obj_operating_table`).

В новой клинике (один кабинет приёма) в списке останется только
«НА ПРИЁМЕ». Построил операционную — кнопки появились. Тот же список
используется и для кликов, поэтому нажать несуществующее место
нельзя.

## Установка — один файл

| файл | куда |
|---|---|
| `FULL/tablet_draw_staff_card_FULL.gml` | скрипт `tablet_draw_staff_card`, заменить целиком |

## Проверено

- статический линтер: одно прежнее замечание (par_staff, не относится);
- список мест собирается в единственном месте кода (поиск по
  `op_surgeon`), клики используют тот же массив;
- копия в пакете совпадает с исходником по md5.

## Не проверялось

Запуск в GameMaker (нет `.yyp`). Открой карточку сотрудника в новой
клинике — в списке «МЕСТО» должен быть только «НА ПРИЁМЕ».
