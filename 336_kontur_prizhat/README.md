# Пакет №336 — контур прижат к полоске, толщина 2

По твоему скриншоту: снаружи цветной полоски оставалась пустая
капсула-контур с прозрачной серединой (раньше её заполнял серый
фон, который мы убрали). Теперь:

- **контура-«пустышки» больше нет** — чёрная обводка рисуется
  ВОКРУГ ЦВЕТНОЙ ЗАЛИВКИ и движется вместе с ней: терпения меньше →
  короче и цвет, и обводка;
- **внутри контура пустоты нет** — обводка прижата к цвету вплотную;
- **контур толще**: 2 пикселя вместо 1.

Стиль — №2 «СТЕКЛО» (`WAIT_BAR_STYLE = 2`). Торцы по-прежнему
круглые (круги/ломаные дуги, пакеты №334/№335), позиция над головой
не менялась.

Картинки: `PREVIEW_STYLES.png`, `PREVIEW_COLORS.png`.

| файл | куда |
|---|---|

## Проверено

- статический линтер: одно прежнее замечание, не относится к пакету;
- контур вызывается только по боксу заливки и только когда заливка
  есть (нет заливки — нет и контура);
- превью собрано из тех же формул, что игровой код;
- копия в пакете совпадает с исходником по md5.

## Не проверялось

Запуск в GameMaker (нет `.yyp`). После установки: полоска = цвет,
обнятый чёрным контуром толщиной 2, без пустой капсулы вокруг.
