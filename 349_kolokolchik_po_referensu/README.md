# ПАКЕТ №349 — КОЛОКОЛЬЧИК ПО ВАШЕМУ РЕФЕРЕНСУ

Иконка на кнопке колокольчика переделана по присланной картинке:

- **колечко с дыркой** сверху (петелька);
- **круглые плечи** купола;
- **ровные бока** с плавным развалом книзу;
- **широкий край-юбка** со скруглёнными углами;
- **отдельный язычок** внизу, отделённый щелью.

Цвета — ваши, проектные: иконка тёмно-коричневая (58, 39, 24),
дырка колечка и щель над язычком рисуются цветом заливки кнопки —
при наведении и в открытом состоянии всё остаётся в цвете кнопки.

Силуэт собран ТОЛЬКО из fill-кругов, fill-полос и одного
draw_roundrect_ext — на телефоне эти примитивы рисуются надёжно
(никаких draw_primitive_* и draw_arc).

Превью формы: `kolokolchik_final_preview.png` в корне рабочей
области (нарисовано один в один теми же формулами, что и в коде).
