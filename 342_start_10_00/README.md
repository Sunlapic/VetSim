# Пакет №342 — новая игра начинается в 10:00

Твоя просьба: «день всегда в новой игре начинается в 8:00.
Давай сделаем в 10:00».

## Что меняется

- `vet_new_game` — при старте новой игры `game_hour = 10`;
- `obj_render → Create` — запасное значение утра тоже 10:00
  (используется только пока время ещё не инициализировано).

Сохранённые игры не трогаются: время читается из сохранения.
Смена суток по-прежнему в 00:00, владельцы за выздоровевшими
приходят с 8:00 до 22:00 (пакет №341 чинит их ходьбу).

## Установка — порядок

1. `FULL/vet_new_game_FULL.gml` → скрипт `vet_new_game`, заменить
   целиком.
2. `FULL/obj_Render_Create_0_FULL.gml` → событие **Create** объекта
   `obj_render`, заменить целиком.

После установки начни НОВУЮ игру, чтобы увидеть 10:00 на часах.

## Проверено

- статический линтер: одно прежнее замечание (par_staff, не относится);
- копии в пакете совпадают с исходниками по md5.

## Не проверялось

Запуск в GameMaker (нет `.yyp`).
