ширина каждой считается по формуле:

- верх и бока — почти ровные (0.56 → 0.63 радиуса);
- нижняя треть — квадратичный развал к краю (до 0.97).

Шаг в 1 экранный пиксель — ступенек не видно ни на каком размере
кнопки. Остальное (колечко с дыркой, плечи-круг, край-юбка, язычок
со щелью, цвета) не менялось.
