# ПАКЕТ №347 — КОЛОКОЛЬЧИК, КАЧЕСТВО ПЕРСОНАЛА, ПРОКАЧКА БЕЗ РАБОТЫ

Три вещи одним пакетом:

1. **Просьбы о прибавке наконец видно.** Система просьб существовала
   с пакета №320, но ни один интерфейс её не показывал — поэтому вы
   не видели ни одной просьбы. Теперь рядом с шестерёнкой стоит
   **кнопка-колокольчик** того же размера:
   - красный кружок с числом — есть непрочитанные просьбы;
   - тап — панель со всеми просьбами (из текущей И неактивных клиник);
   - у каждой просьбы кнопки **ДА / НЕТ**;
   - текст как договаривались: «Николай Грачёв поднял навык
     «ТЕРАПИЯ» с 3 по 5 лвл, просит поднять зарплату со 140 до 150»;
   - на ответ **3 дня**, потом просьба отклоняется сама (со штрафом
     к лояльности, как обычный отказ).
   - Отказ бьёт по лояльности (−20/−30/−40), после 3 отказов или
     при нулевой лояльности сотрудник увольняется — и в активной
     клинике, и в неактивной.
   - Потом в этот же колокольчик можно класть и другие сообщения
     по клиникам — очередь общая.

2. **Пассивный доход зависит от качества персонала.** Формула дня:
   `(база + бонус развития) × люди × качество`, где
   - люди = min(1, число сотрудников / 3) — как было;
   - качество = 0.7 + 0.06 × средний профильный уровень штата:
     новички (ур.1) → ×0.76, середнячки (ур.5) → ×1.00,
     мастера (ур.10) → ×1.30.
   Пустая клиника по-прежнему не приносит ничего.

3. **Сотрудники неактивных клиник понемногу прокачиваются.**
   Раз в день каждый получает **24 пункта опыта** (не уровень!)
   в навык по своей работе:
   - врач на приёме → ТЕРАПИЯ; хирург → ХИРУРГИЯ;
     анестезиолог → АНАСТЕЗИОЛОГИЯ; стационар → СТАЦИОНАР;
   - ассистент → ПРОЦЕДУРЫ; администратор → РЕГИСТРАТУРА.
   Уровень стоит 30 + (лвл−1)×20 пунктов, поэтому 2-й уровень
   приходит за полтора дня простоя, а 10-й — за неделю-полторы.
   Рост навыков копится и может породить просьбу о прибавке —
   она придёт в колокольчик.

## Порядок установки

1. Заменить содержимое скриптов 1–3.
2. Создать новый скрипт `hud_bell_system` и вставить файл 4.
3. Заменить события объектов (5–8).
4. Всё, ничего больше создавать не нужно.

## Что проверить в игре

1. Колокольчик появился слева от шестерёнки, того же размера.
2. Прокачайте врача на 3+ уровня в навыках — через день-другой
   колокольчик загорится красным; в панели — просьба с ДА/НЕТ.
3. «ДА» — зарплата выросла (карточка сотрудника), «НЕТ» — падает
   лояльность; три отказа — сотрудник уходит.
4. Оставьте просьбу без ответа на 3 дня — она исчезнет сама,
   лояльность упадёт.
5. Купите вторую клинику, наймите туда людей, уйдите в первую:
   доход второй растёт с развитием и качеством штата, а через
   несколько дней её сотрудники прокачаются и тоже попросят
   прибавку (в просьбе будет название их клиники).
6. Увольте всех во второй клинике — её доход станет 0.
