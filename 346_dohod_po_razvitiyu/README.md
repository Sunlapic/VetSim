# Пакет №346 — пассивный доход растёт с развитием клиники

Твоя просьба: «чем сильнее развита клиника, тем выше её пассивный
доход». Раньше доход был фиксированный из данных клиники
(600/1500/2600/4200) и не зависел от построек.

## Как теперь считается

Пассивный доход в день = базовый `income_per_day` клиники
**+ бонус развития** за купленные комнаты:

| постройка | прибавка в день |
|---|---|
| кабинет приёма сверх первого | +200 |
| палата стационара | +300 |
| каждая койка | +150 |
| операционная | +600 |

Пример: клиника №4 полностью развитая (5 лишних кабинетов, палата,
8 коек, операционная) = 4200 + 1000 + 300 + 1200 + 600 = **7300/день**
(до множителя за штат: полный доход при трёх сотрудниках, как было).

Цифры прибавок подобраны мной — если хочешь другие, скажи, поменяю
одним местом в `clinic_development_bonus`.

## Где работает

- ежедневное начисление прочим клиникам (`clinic_network_daily_income`)
  теперь считает базу + бонус;
- карта клиник показывает «+$…/д» и «Доход в день» тоже с бонусом —
  видно, как развитие поднимает доход.

Активная клиника, где ты играешь руками, пассивный доход не получает
(как и раньше) — у неё живая выручка с приёмов.

## Установка — два файла, порядок

1. `FULL/clinic_network_system_FULL.gml` → скрипт
   `clinic_network_system`, заменить целиком.
2. `FULL/clinics_map_panel_FULL.gml` → скрипт `clinics_map_panel`,
   заменить целиком.

## Проверено

- статический линтер: одно прежнее замечание (par_staff, не относится);
- бонус читает покупки из `clinic_rooms_open` (активная клиника) или
  из кармана клиники `state.rooms` (остальные); некупленная клиника
  даёт бонус 0;
- обе копии в пакете совпадают с исходниками по md5.

## Не проверялось

Запуск в GameMaker (нет `.yyp`). Купи во второй клинике кабинет или
палату — на карте её «+$…/д» должен вырасти.
