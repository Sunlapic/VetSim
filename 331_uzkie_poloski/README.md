# Пакет №331 — узкие полоски без серого фона: только цвет и обводка

Переделка шкал из пакета №330 по твоей правке:

- **Уже**: высота 8 → 6 (`WAIT_BAR_HEIGHT`).
- **Без серой дорожки внутри**: рисуется только цветная заливка.
- **Обводка обнимает сам цвет**: чёрный контур идёт вокруг заливки,
  а не вокруг пустой дорожки — полоска выглядит как цветная капсула.

Позиция над головой, цвета по типу ожидания и клавиша V — без zmian,
как в №330.

Картинки в папке: `PREVIEW_STYLES.png` (шесть вариантов на границе
тёмного и светлого фона), `PREVIEW_COLORS.png` (палитра).

## Шесть вариантов (WAIT_BAR_STYLE = 1–6)

| № | Вариант | Вид |
|---|---|---|
| 1 | КАПСУЛА | градиент + блик сверху |
| 2 | СТЕКЛО | блик-овал, как капля |
| 3 | СЕГМЕНТЫ | капсула с чёрными рисками на 10 делений |
| 4 | НЕОН | свечение вокруг цвета + яркая сердцевина |
| 5 | МЕТАЛЛ | плоский цвет со светлой и тёмной кромками |
| 6 | ЛИНИЯ | самая тонкая (3 px) + белая метка конца |

Когда терпения остаётся мало, заливка просто становится короче —
обводка уходит вместе с цветом, лишнего серого не остаётся.

Если №330 **уже стоит**: просто перекрой два файла.

| № | Файл пакета | Куда в GameMaker |
