# Пакет №340 — врач стационара всегда садится на место

Твоя жалоба: врач стационара не всегда садится на место, стоит
рядом и дёргается.

## Причина (найдена в коде)

1. В состоянии ходьбы к стулу (`inpatient_moving_to_chair`) функция
   `inpatient_update_staff_animation` каждый кадр ставила
   `is_walking = true`, даже когда пути уже не было. Персонаж
   проигрывал ходьбу на месте («дёргался»), а
   `inpatient_ensure_walk` считал его «уже идущим» и не
   перестраивал путь, если первый путь закончился раньше цели.
2. Если путь к стулу вообще не строился (точка недостижима), врач
   оставался стоять навсегда — страховки сесть не было.

## Исправление

- `is_walking = true` теперь только при живом пути
  (`path_index != -1 && path_position < 1`);
- в контроллере: не удалось построить путь к стулу (и при возврате
  к стулу после назначений) — врач сажается сразу: состояние
  `inpatient_at_chair` сам ставит его в точку отдыха.

## Установка — один файл

| файл | куда |
|---|---|
| `NEW_SCRIPT/inpatient_system/inpatient_system_FULL.gml` | скрипт `inpatient_system` — заменить содержимое целиком |

Скрипт полосок ожидания (`wait_bar_system`) из №339 не трогай, если
уже поставил его.

## Проверено

- статический линтер: одно прежнее замечание (par_staff, не относится);
- копия в пакете совпадает с исходником по md5.

## Не проверялось

Запуск в GameMaker (нет `.yyp`). Посмотри: свободный врач
стационара должен доходить до стула и садиться; если путь
непроходим — садится сразу без дёрганья.
