# ПАКЕТ №348 — БОЛЬШОЕ ОКНО УВЕДОМЛЕНИЙ, КРУПНЫЙ ШРИФТ

Правка одного скрипта из пакета №347: окно колокольчика стало
большим и читаемым.

## Что изменилось

- **Окно почти на весь экран**: ширина `экран − 24 px` (до 940),
  высота по числу сообщений (до `экран − 24`). Раньше было
  640 px и мелкая строка в 136 px.
- **Крупный шрифт** — всё поднято на два шага шкалы:
  - заголовок окна «УВЕДОМЛЕНИЯ» — как был, крупный (UI_FS_TITLE);
  - имя сотрудника и клиника — UI_FS_HEADER (было UI_FS_ROW);
  - «поднял навык «ТЕРАПИЯ» с 3 по 5 лвл» — UI_FS_VALUE;
  - «просит поднять зарплату со 140 до 150» — UI_FS_VALUE;
  - «на ответ 3 дн.» — UI_FS_ROW (было UI_FS_SMALL).
- **Крупные кнопки ДА / НЕТ**: 176×92 px (были 104×62) — под палец.
- **Крупный крестик** закрытия: 62×62 px.
- **Пустое окно**: по центру крупная надпись
  **«НОВЫХ СООБЩЕНИЙ НЕТ»** (заголовок окна переименован
  в «УВЕДОМЛЕНИЯ» — туда потом лягут и другие сообщения по клиникам).
- Красный кружок на кнопке чуть крупнее (радиус 17), число в нём —
  шрифтом строки.

Логика не менялась: очередь та же, ДА/НЕТ те же, 3 дня на ответ.
