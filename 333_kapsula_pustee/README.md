# Пакет №333 — капсула пустеет: обводка постоянная, цвет укорачивается

Две правки оформления по твоему замечанию к №331/№332:

1. **Обводка больше не уменьшается.** Чёрный контур — постоянная
   капсула во всю ширину полоски. Когда терпения остаётся меньше,
   цвет внутри укорачивается, а капсула **пустеет**: пустая часть
   прозрачная (серого фона по-прежнему нет).
2. **Края круглые, не квадратные.** Радиус скругления — половина
   высоты капсулы, и добавлен `draw_set_circle_precision(32)`:
   на стандартной точности маленькие радиусы в GameMaker рисовались
   угловато.

Стиль — **№2 «СТЕКЛО»** (`WAIT_BAR_STYLE = 2`), как ты выбрал.
Позиция над головой и цвета по типу ожидания не менялись.

Картинки: `PREVIEW_STYLES.png` — все шесть вариантов с новой логикой
(капсула одна и та же, цвет внутри разной длины), `PREVIEW_COLORS.png`
— палитра на стиле №2.
