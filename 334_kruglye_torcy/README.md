# Пакет №334 — круглые торцы и постоянная капсула (стиль №2 «СТЕКЛО»)

Разбор твоего скриншота показал две вещи:

1. **Углы выглядели квадратными**, потому что `draw_roundrect_ext`
   с маленьким радиусом в игре съедает скругление. Теперь торцы
   капсулы рисуются **явными дугами** (`draw_arc`) и кругами
   (`draw_circle` для заливки) — круг есть круг в любой версии
   GameMaker.
2. **Обводка постоянная.** Чёрный контур — капсула во всю ширину
   полоски, он НЕ укорачивается. Цвет внутри двигается сам: терпения
   меньше → цвет короче → **капсула пустеет**, пустая часть
   прозрачная (серого фона нет).

Стиль — **№2 «СТЕКЛО»** (`WAIT_BAR_STYLE = 2`), как ты выбрал.

Картинки: `PREVIEW_STYLES.png` (все шесть вариантов: контур один и
тот же, цвет разной длины), `PREVIEW_COLORS.png` (палитра на стекле).

## Проверено

- статический линтер: одно прежнее замечание, не относится к пакету;
- в обводке нет полных кругов (`draw_circle …, true` давал лишнее
  кольцо внутри капсулы) — только внешние полуокружности `draw_arc`
  90–270 и 270–450 плюс две линии;
- превью собрано из тех же формул, что игровой код.
