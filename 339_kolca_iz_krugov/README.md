# Пакет №339 — торцы обводки кольцами из залитых кругов

Твой скриншот: от обводки остались только две полоски — сверху и
снизу. Значит, треугольники `draw_primitive_*` из №338 в твоём
GameMaker **вообще не нарисовались**, а прямоугольники — да.

## Исправление

Торцы капсулы теперь собираются из самых надёжных примитивов —
**залитых кругов** (`draw_circle …, false`): 15 маленьких кругов по
среднему радиусу полуокружности сливаются в сплошное кольцо
толщиной 2. Верх и низ — залитые прямоугольники (они у тебя
рисуются). Никаких draw_line, draw_arc, draw_primitive в обводке.

Поведение то же, что №337–338: обводка постоянная по всей капсуле,
при полной полоске цвет впритык, уменьшается — пустота внутри,
обводка не меняется; толщина 2; стиль №2 «СТЕКЛО».

Картинки: `PREVIEW_STYLES.png`, `PREVIEW_COLORS.png`.

## Проверено

- в обводке остались только draw_rectangle и draw_circle (залитые) —
  обе функции существуют во всех версиях GameMaker;
- статический линтер: одно прежнее замечание, не относится к пакету;
- превью собрано из тех же формул, что игровой код;
- копия в пакете совпадает с исходником по md5.
