# Пакет №338 — обводка ЗАЛИТЫМИ фигурами (не две тонкие линии)

Твой скриншот: обводка выглядела как две тонкие линии с щелью
между ними. Причина в масштабировании окна: координаты
масштабируются, а `draw_line` всё равно рисует 1 экранный пиксель —
моя «лента из штрихов» (пакет №337) распадалась на раздельные
линии. Заливка (прямоугольники/круги) при этом масштабируется
честно.

## Исправление

Обводка больше не использует `draw_line`:

- верх и низ — **залитые прямоугольники** высотой 2;
- торцы — **залитые полукольца** из треугольников
  (`draw_primitive_begin/draw_vertex/draw_primitive_end` — функции
  из древних версий GameMaker, один аргумент у begin).

Толщина та же — 2, но теперь это сплошная лента при любом
масштабе. Всё остальное как в №337: обводка постоянная по всей
капсуле, цвет впритык при полной полоске, пустеет внутри; стиль
№2 «СТЕКЛО»; торцы круглые.

Картинки: `PREVIEW_STYLES.png`, `PREVIEW_COLORS.png`.

## Проверено

- в скрипте нет `draw_line` для обводки (остался только в стилях
  для бликов — они внутри цвета и на толщину не влияют);
- статический линтер: одно прежнее замечание, не относится к пакету;
- превью собрано из тех же формул, что игровой код;
- копия в пакете совпадает с исходником по md5.

## Не проверялось

Запуск в GameMaker (нет `.yyp`). После установки обводка должна быть
сплошной чёрной лентой толщиной 2 вокруг постоянной капсулы.
