# Пакет №345 — ОДИН пакет: меню мест по покупке + палата на 1 койку

Собрал обе правки в один пакет, как ты попросил. Включает правки
№343 и №344 (пакет 344 закрыт, отдельно ставить НЕ надо).

## А. Меню «МЕСТО» — только купленные помещения

Раньше (№343) я проверял объекты в комнате, а они стоят всегда —
во второй клинике без открытого стаца всё равно было «СТАЦИОНАР».
Теперь список собирается по данным покупок:

- **СТАЦИОНАР** — только если палата куплена (`clinic_ward_is_open()`);
- **ХИРУРГ / АНЕСТЕЗИОЛОГ / ОПЕРАЦИОННАЯ** — только если операционная
  предусмотрена и куплена (`clinic_operating_is_open()`);
- иначе только «НА ПРИЁМЕ».

## Б. Прокачка стационара: палата = 1 койка

- покупка палаты открывает **только койку 101**;
- койка **102** — отдельная покупка в дереве за $1200, дальше
  цепочкой (103 требует 102 и т.д.);
- подпись палаты — «палата на одну койку»;
- мебель второй койки скрыта до покупки;
- старые сохранения с купленной по-старому палатой не ломаются
  (флаг 102 у них сохранён).

## Установка — три файла, порядок

1. `FULL/tablet_draw_staff_card_FULL.gml` → скрипт
   `tablet_draw_staff_card`, заменить целиком.
2. `FULL/clinic_rooms_system_FULL.gml` → скрипт `clinic_rooms_system`,
   заменить целиком.
3. `FULL/clinic_tree_panel_FULL.gml` → скрипт `clinic_tree_panel`,
   заменить целиком.

## Проверено

- статический линтер: одно прежнее замечание (par_staff, не относится);
- покупка палаты больше не выставляет bed_102 (поиск по коду);
- меню читает данные покупок, а не объекты комнаты;
- все три копии в пакете совпадают с исходниками по md5.
