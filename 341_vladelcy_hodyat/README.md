# Пакет №341 — владельцы забирают выздоровевших НОГАМИ, без телепорта

Твоя жалоба: в 8:00 владельцы идут до клиники, а на входе
телепортируются в стационар к животным. Так быть не должно.

## Что нашлось в коде

Движением владельца, пришедшего за выздоровевшим питомцем,
владели сразу два «костыля»:

1. состояние `going_to_exam` у владельца: если маршрут по сетке не
   построен — идти НАПРЯМУЮ (`move_towards_point`, сквозь стены), а
   после трёх попыток — **телепорт** в целевую точку;
2. контроллер палаты в фазе `owner_returning` тоже толкал владельца
   напрямую `move_towards_point`, когда путь заканчивался.

Отсюда картинка «дошёл до входа — и исчез в стационаре».

## Исправление

- владелец помечается флагом `inpatient_returning`;
- в `going_to_exam` для него отключены прямая доводка, таймеры
  попыток и телепорт; по приходе он не переходит в `in_exam` —
  выдачу завершает палата;
- контроллер палаты ведёт его только маршрутом по сетке
  (`inpatient_ensure_walk` — тот же механизм, которым ходят все);
- аварийная страховка: если путь не строится 90 секунд подряд
  (кто-то надолго загородил проход) — только тогда владелец
  ставится в точку, чтобы выдача не зависла навсегда.

ВАЖНО: этот пакет полностью включает правки пакета №340 (врач
садится на стул). Если №340 ты не ставил — просто поставь №341,
он заменяет оба. Если №340 уже стоит — всё равно ставь №341
(файл новее).

## Установка — порядок

1. `NEW_SCRIPT/inpatient_system/inpatient_system_FULL.gml` → скрипт
   `inpatient_system`, заменить целиком.
2. `FULL/obj_owner_Step_0_FULL.gml` → событие **Step** объекта
   `obj_owner`, заменить целиком.

## Проверено

- статический линтер: одно прежнее замечание (par_staff, не относится);
- в пути возвратника больше нет move_towards_point и телепорта после
  трёх попыток (поиск по коду);
- копии в пакете совпадают с исходниками по md5.

## Не проверялось

Запуск в GameMaker (нет `.yyp`). Утром владелец должен зайти в
клинику и дойти до стационара по полу, без исчезновений. Если
всё же увидишь телепорт — пришли скриншот и время на часах игры.
